# Arizon E-commerce Frontend

A modern e-commerce frontend built with React.js and Tailwind CSS.

## Features

- 🛍️ Product browsing and shopping cart functionality
- 🌓 Dark mode support
- 🔍 Product search and filtering
- 📱 Fully responsive design
- 🛒 Persistent shopping cart
- ⚡ Real-time cart updates

## Tech Stack

- React.js
- Tailwind CSS
- React Router
- Zustand (State Management)
- Fake Store API
